# Mal Spending Recap prototype

Prototype of the Mal chat assistant answering
"Hey! Can you tell me how my spending was last month?"

Two builds of the same flow live here:

| Path | What it is |
| --- | --- |
| `Mal.xcodeproj` + `Mal/` | Native SwiftUI iOS app (iOS 17+). Open in Xcode, run on your iPhone. |
| `index.html` | Web version. Open in a browser, or add to the iPhone home screen from Safari. |

Flow covered: home screen → user question → reasoning steps → one-sentence answer
with a spending card → category drill-down → Round-Up Savings moment → monthly
recap opt-in. All data is illustrative (August 2026 vs July 2026, AED).

## Run the iOS app on your iPhone

1. Install Xcode 16 or newer from the Mac App Store.
2. `git clone https://github.com/gkzoe/mal.git` and open `Mal.xcodeproj`.
3. Xcode → Settings → Accounts → add your Apple ID (a free account is enough).
4. Select the **Mal** target → **Signing & Capabilities** → tick *Automatically manage signing*
   and pick your personal team. If Xcode complains the bundle ID is taken, change
   `com.zoe.mal.prototype` to anything unique.
5. Plug in your iPhone, unlock it, and tap *Trust* when asked. On the phone, turn on
   Settings → Privacy & Security → Developer Mode (iOS 16+), then restart it.
6. Choose your iPhone in the device picker at the top of Xcode and press ▶ (Cmd+R).
7. First launch only: on the phone go to Settings → General → VPN & Device Management
   → your Apple ID → *Trust*. Then open Mal from the home screen.

Apps signed with a free account expire after 7 days; press ▶ again to reinstall.

If Xcode refuses to open `Mal.xcodeproj` (it was generated by hand), create a new
iOS App project named *Mal* with SwiftUI, delete its `ContentView.swift`, and drag the
`Mal/` folder's Swift files and `Assets.xcassets` into the project.
